# chatbot

This repository is a project focused on creating a chatbot that answers specific questions about Universidade Federal do ABC (UFABC), regarding things like dates, classes and enrollment. 

## Project Architecture
This project is implementing a local model running in ollama that will use the RAG technique to have access to specific information regarding UFABC. The backend is being developed in Python and the fronted is in TypeScript, using the React framework.
